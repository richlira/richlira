## Current Projects

- 🧭 **[compass-mcp](https://github.com/richlira/compass-mcp)** — Open-source TypeScript MCP server that bridges Claude Chat, Cowork, and Code through a shared markdown layer, so context travels with you across surfaces.
- 🗣️ **[spanglish-mexa-7b](https://huggingface.co/richlira/spanglish-mexa-7b)** — Open model focused on Spanglish and code-switching for LatAm use cases. Part of my push toward edge and on-device AI that actually speaks how my community speaks.
- 🧠 **[MeetingMindAI](https://github.com/richlira/MeetingMindAI)** — AI meeting assistant for iPhone: real-time transcription, intelligent questions, and summaries. Swappable cloud (Whisper plus Claude) and on-device (SpeechAnalyzer plus Foundation Models) providers. Zero dependencies, pure Swift 6.
- 🏠 **Hermes (homelab)** — Self-hosted AI assistant running on an NVIDIA DGX Spark, orchestrating scheduled jobs and LLM-powered briefings. My playground for local inference and edge AI.
